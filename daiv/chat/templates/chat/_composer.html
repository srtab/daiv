{% load i18n icon_tags %} {% comment %} Chat composer. Anatomy, top to bottom inside the sticky dock: - **Progress drawer** — tucked behind the composer's top edge, naming the step the run is on; it opens upwards in place into todos and files changed (``_progress_drawer.html``). - **Composer** — one row: the options trigger (``+``), the textarea, then the context ring, the model as plain text, and an icon-only Send / Stop. A new chat's repositories and environment are set in the Workspace card above the dock (``_workspace_card.html``). Everything else that isn't acted on lives one tap away, and nothing appears twice: MCP servers in the options sheet, todos and files changed in the drawer. The sheets are bottom sheets below 1100px and popovers anchored above their trigger at or above it — same markup, only the container differs (see ``.composer-sheet`` in input.css). Typing ``/`` as the draft's first token opens the command autocomplete above the composer box (``_command_menu.html``). {% endcomment %}
