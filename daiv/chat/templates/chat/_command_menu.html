{% load i18n icon_tags %} {% comment %} "/" autocomplete: slash commands + global skills, filtered as the user types the leading token. Visibility mirrors the bare-command regex in ``slash_commands/parser.py`` — the menu lives while the draft is still just ``/token`` and closes once a space follows. Deliberately not a ``.picker-popover`` and not a bottom sheet: it spans the composer's own width, so the phone-overflow problem that forces trigger-anchored pickers into sheets never applies, and a bottom sheet would cover the textarea being typed in. One geometry at every width, anchored above the composer box (``.chat-composer`` is the positioned ancestor). {% endcomment %}
