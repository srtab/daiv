# Community

DAIV is open-source and contributions are welcome — code, documentation, testing, or feedback.

## Contributing

For contribution guidelines, code style, testing requirements, and the pull request process, see [CONTRIBUTING.md](https://github.com/srtab/daiv/blob/main/CONTRIBUTING.md).

## Questions and ideas

Ask for setup help and share ideas in [GitHub Discussions](https://github.com/srtab/daiv/discussions).

## Reporting issues

Use [GitHub Issues](https://github.com/srtab/daiv/issues) for bug reports and feature requests. Search existing issues first; the issue forms ask for the version, platform and logs a report needs.

Report security vulnerabilities privately, as described in the [security policy](https://github.com/srtab/daiv/blob/main/SECURITY.md), never in a public issue.

## Code of conduct

Everyone taking part in the project is expected to follow the [Code of Conduct](https://github.com/srtab/daiv/blob/main/CODE_OF_CONDUCT.md).
